## [1.0.1] - 2026-11-13

First public release.

### Added

- Named workspaces with recording-first sidebar.
- Live guitar monitoring gated on a connected Tankpedal KPT Pro over USB.
- Multitrack recording with backing tracks, multi-clip tracks, split, move, rename and bounce.
- Audio import for WAV, MP3, FLAC, M4A and Ogg.
- Release installers for macOS (Apple Silicon and Intel), Windows and Linux.
